# Context Desk design direction

A lively production desk for creators who need to move quickly. The visual system uses a pale lilac canvas, dark plum header and monitor surfaces, violet typography, lime actions, lavender queue panels, and coral manual-mark controls. Bricolage Grotesque gives the editorial headings character; DM Sans keeps controls readable. Motion is brief and functional. The layout works from one column on phones to monitor-plus-queue on desktop.

The interaction order is source, live scan, moment review, then cut. The editor has a visible source-linked preview and editable hook; framing and title options stay tucked into a disclosure. Caption translation is explicitly marked as draft and paired with a source transcript and per-language review control. No sample data impersonates a real analysis result.

## Studio workflow revision

A restrained branded studio uses a dark plum header, pale violet workspace, purple edit actions and lime source/generation actions. Persistent three-stage navigation keeps source setup, clip generation, and editing separate. A sticky loading panel names the current task and shows elapsed seconds without blocking navigation. Completed windows show real sampled thumbnails. Advanced evidence, subtitle controls, and multi-clip stories use disclosures. File selection uses a clipped native input within its label, avoiding a full invisible input over the upload action.

## Artwork and long-form revision

The entry screen pairs a concise source form with an original full-bleed editorial still life: sculptural violet film strip, lime paper frame and physical recording/playhead details. A custom geometric film/play mark anchors the wordmark. The image is served as a 221 KB WebP; its original PNG and generation prompt remain in `public/assets`. Display type has a clear two-line hierarchy, while labels and controls retain readable sizes and strong contrast. The split entry layout becomes form-first on mobile and disappears once a source is connected, keeping artwork out of the editing workspace.

The default remains one link and Make clips. Discovery depth is optional. Long recordings show local preparation before the scan; source changes abort pending local upload work and ignore stale readiness callbacks. The six-hour/four-GB ceiling is stated beside the source field.


## Replay and transcript correction

The dark preview transport groups Play, Restart and optional Loop clip above the scrubber. Each remains touch-sized; the R shortcut is documented beside Space and trim shortcuts. Caption correction defaults to editable line text with a timestamp button to listen from that line. Raw timing syntax is available through Advanced line timings. A compact sync block names the direction and amount of timing adjustment; preview and export share one offset transform. The active transcript row uses a lilac fill rather than an accent border. Caption look reuse is a separate action and does not imply wording or timing approval.
