# Context Desk V2 — consolidated build brief

Accepted direction: 1 November 2026. This consolidates both supplied master briefs, the illustrative video-first screenshot, and the earlier product requests. It is a build contract, not a claim that every requested capability is complete.

## Product and audience

Context Desk turns a permissioned recording or user-shared live source into editable, source-linked story moments and multilingual captioned exports. One simple default serves solo streamers and unscripted/reality producers. Preserve the source question, response, chronology and immediate consequence; suspense must come from the footage. Never invent quotes, reactions, relationships, certainty or guaranteed engagement.

## Essential experience

Library → import a URL/file and choose source/output language → automatic bounded discovery → watch the original next to candidate moments → edit boundaries, framing, wording and subtitle timing → review captions → export a real video → reopen saved work. Live sources need the browser share permission and audio choice; do not promise universal direct ingestion. An uploaded recording supports batch discovery across its duration rather than only one clip. Existing limits remain explicit: six hours, local file up to 20 GB, platform downloads fit a working budget.

Discover must keep the original video visible. A Moment Map shows actual checked intervals and unreviewed gaps. Search and filters operate on retained text/evidence and never claim to understand footage that was not processed. Studio keeps preview, transport and real trim boundaries central, with captions and evidence beside them. Advanced tools use progressive disclosure. Library, Jobs, import and Settings share one coherent design system.

## Engineering invariants

Retain Node, browser modules, SQLite project revisions, stable managed media, durable queues/caches, FFmpeg render decisions and known recovery fixes. One instance of each canonical DOM control. Keep stored workspace values source/clips/edit/library/jobs for compatibility. Never upload `.env`, databases, footage, transcripts or model outputs to Git. Never silently repeat ambiguous provider calls after refresh. Save feedback follows server acknowledgement. New presentation must not replace the project/history/job owners.

Use Meta Muse Spark for grounded sampled visual/story reasoning and contextual translation; Muse Voice for source transcription; optional installed VoiceStudio for local speech/translation where supported. Provider configuration is not proof of a successful request. Reuse cached work, expose actual usage and bound discovery. SAM-based automatic moving-subject tracking requires a separate integration/evaluation; never label manual framing as SAM.

## Language and captions

Generate a fresh transcript from source audio; do not import YouTube captions. Dialects are optional context with code-switch/name/glossary hints, not universal recognition guarantees or attractiveness/emotion classification. Preserve original ASR, distinguish native word timestamps from estimated turn timing, support RTL and per-language review. Automatic language changes reuse translations where possible. Full-recording subtitle jobs remain separate from moment translation. Styled subtitles must remain faithful and readable; uncertainty and manual corrections survive refresh. Actual bilingual/dialect validation remains a release gate.

## Priorities and verification

P0: coherent working app, durable projects, clear navigation/import, sorting, named progress/recovery, language setup, source-linked discovery, editable clips/captions and reliable exports. P1: meaningful moment search, context evidence, better review, framing assistance and source-aware sequence assembly. P2: advanced live/platform ingestion, cross-episode automation, sophisticated audio/colour, dubbing, multicamera, scheduling and collaboration.

Prove desktop 1440/1280, tablet 768 and mobile 390; keyboard/focus, contrast, RTL, reduced motion, loading/empty/error states, no horizontal clipping, project refresh/restart recovery and actual audio/video/subtitle export. Use real permissioned footage for the final editorial demo; synthetic QA fixtures do not establish reality-show clipping quality. Document measured outcomes and remaining gates. A three-minute demo should show meaningful Meta reasoning, inspectable source context, a corrected caption, a real export and refresh recovery. No victory or competition eligibility guarantee.
