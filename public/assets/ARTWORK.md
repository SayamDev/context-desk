# Context Desk original studio artwork

Created with the built-in image generation tool for this project. No reference image was supplied.

- Original project asset: `context-desk-studio.png`
- Optimized web asset: `context-desk-studio.webp` (220,606 bytes)
- The PNG was converted to WebP with Pillow for delivery; its composition was not edited.

## Prompt

Use case: stylized-concept. Create original premium editorial brand artwork for Context Desk, a Gen Z unscripted video clipping and editing studio. Wide landscape composition, 3:2 aspect. A tactile art-directed assemblage: a vivid violet sculptural ribbon shaped like a film strip looping through a lime-green cut paper frame, reflective black-chrome playhead and coral red physical recording dot, a few photographic contact-sheet frames containing abstract defocused performance silhouettes with no identifiable faces. One cohesive still life with dynamic diagonal movement, not a collection of generic floating app icons. Matte lilac studio backdrop, hard directional photographic shadows, tangible paper and polished metal details, fashion editorial / independent music magazine attitude, slightly offbeat and exuberant yet professionally crafted. Palette purple #7752f4, electric chartreuse #caff45, near-black #1f192d, soft lilac #eae1ff, small coral red. Artwork only, no typography, no words, no letters, no watermark, no rendered website or UI. Full bleed with most visual interest in center/right; usable as a vertical cropped studio artwork panel beside a white task form. Save a local image asset for integration into the app.

## V2 wordmark type

Manrope variable font, locally hosted as `fonts/Manrope.ttf`, downloaded 1 November 2026 from the [official Google Fonts source](https://github.com/google/fonts/tree/main/ofl/manrope). Unmodified font; the SIL Open Font License and copyright notice are retained in `fonts/Manrope-OFL.txt`. Manrope is used for the compact wordmark only; functional controls retain the documented system sans. The three-cut brand mark and 24px UI icon paths are original deterministic SVG geometry in `public/layout.js`; they are not competitor assets.
